# Library Management System

This is an independent project developed by **Ritesh Masanta** to apply my knowledge of web development and understand how a real-world Library Management System works.

The project provides a simple and responsive interface for managing different library-related activities such as student registration, teacher registration, book search, book issuing, and other library services.

---

## Website Design

The project has a simple, user-friendly and responsive interface designed using HTML, CSS, JavaScript and Bootstrap.

## Description

- Developed a simple and user-friendly interface for a Library Management System.

- Designed the website using HTML, CSS, JavaScript and Bootstrap.

- Added responsive design so that the website can work on different screen sizes and devices.

- Created different pages for library-related activities.

- Included pages for student registration, teacher registration, college registration, book searching and book issuing.

- Focused on creating a clean and easy-to-use interface.

- Used Bootstrap components to improve responsiveness and overall website design.

---

## Project Features

The website contains different sections and pages, including:

- 🏠 Home Page
- 📚 Library Management
- 🔍 Book Search
